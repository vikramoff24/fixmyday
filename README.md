# FixMyDay

> Your thoughts are messy. Your day doesn't have to be.

FixMyDay is an AI-powered personal planner. Tell it everything on your mind — it understands, organizes, and turns it into a realistic plan you can actually follow.

**Thoughts → AI → Plan → Action**

## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · shadcn/ui · Motion · Lucide · PostgreSQL (Neon) · Drizzle ORM · Clerk · OpenAI · React Hook Form · Zod

## Roadmap

- [ ] Phase 1 — Foundation (setup, design system, layout, routing)
- [ ] Phase 2 — Today experience (timeline, progress, AI capture UI)
- [ ] Phase 3 — Task system (DB, CRUD, auth, detail panel, filters)
- [ ] Phase 4 — AI (structured planning, validation, `/ask` assistant)
- [ ] Phase 5 — Calendar (day/week views, drag-to-reschedule)
- [ ] Phase 6 — Insights
- [ ] Phase 7 — Polish (a11y, responsive, performance, security)
